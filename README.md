# Carnatic Raga Practice Game 🎵

An interactive game-based tool to help you master Carnatic music ragas through engaging learning experiences.

## Features

### 📚 Learn Ragas
Explore different ragas with detailed information including:
- Raga type (Melakarta or Janya)
- Mood and character
- Arohana (ascending) and Avarohana (descending) patterns
- Swaras (notes) used
- Detailed descriptions and practice tips

### 🎯 Identify Raga
Test your ability to recognize ragas by their characteristics:
- Given arohana, avarohana, and mood
- Choose the correct raga from multiple options
- Earn points for correct answers
- Build your streak!

### 🎼 Practice Swaras
Practice individual ragas with:
- Note sequences displayed clearly
- Practice tips specific to each raga
- Random raga selection for comprehensive learning

### ❓ Quiz Mode
Challenge yourself with questions about:
- Raga moods and characteristics
- Raga types (Melakarta vs Janya)
- Arohana and Avarohana patterns
- Points for correct answers

## Scoring System

- **Beginner**: 0-49 points
- **Intermediate**: 50-149 points
- **Advanced**: 150-299 points
- **Master**: 300+ points

## How to Play

1. Open `index.html` in your web browser
2. Choose a learning mode from the menu
3. Complete activities to earn points
4. Track your progress with the scoring system
5. Advance through levels as you improve

## Ragas Included

## Getting Started

1. Clone the repository
